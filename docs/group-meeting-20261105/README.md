## 在 Mac 上使用

在已有仓库的 main 分支拉取最新内容：

~~~sh
git pull --ff-only origin main
~~~

随后打开 docs/group-meeting-20261105。制作 PPT 时优先插入 PNG：图中字体已经栅格化，不依赖 Windows 字体。SVG 可放大或编辑，但文字样式可能随本机字体变化。

源码引用已改为固定公开提交的 GitHub 链接，并核对行号和摘录。无需本机存在 Windows 工作目录。讲义和逐页素材里的配图均为相对路径。

## 阅读顺序

先读讲义第 1 节理解复现与更新流程，再看第 2 节优化原理和第 4 节实验结果，最后按 PPT 逐页讲稿排练。

当前复现是 ToyCircuit 上未加掩码的核心正确性研究原型。主汇报可说“本次 H200 实测的 Setup 阶段加速超过 3 倍”；不能推广为完整系统统一加速比。DAG 仍是未实验的后续方向。

历史实验条件、负结果和验证范围沿用完整成果报告。本次发布仅整理文档，没有新增实验。文件校验值见 [CHECKSUMS.sha256](CHECKSUMS.sha256)；验证完整清单前请把下载的 ZIP 放在本目录。
